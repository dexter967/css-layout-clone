# ⚡ CSS Layout Clone & Aura Sound WebApp

A modern, responsive, and aesthetic web application built with HTML5, CSS Grid, Flexbox, and the Web Audio API. 

This repository contains two distinct modern web application concepts:
1. **SaaSify** — A responsive SaaS deployment landing page with CSS Grid/Flexbox layouts.
2. **Aura Sound** — A minimal, light-aesthetic ambient music player featuring an interactive Web Audio synthesizer, visualizer canvas, and a 3-mode payment gateway modal triggered by an action switch.

---

## 🌟 Features

### 🎧 Aura Sound (Minimal Ambient WebApp)
- **Aesthetic Pastel Light Theme:** Built with soft color gradients, high readability, and clean typography (`Plus Jakarta Sans`).
- **Interactive Audio Synthesizer:** Built-in procedural Web Audio API synth that generates soft ambient waves dynamically without external audio files.
- **Canvas Waveform Visualizer:** Real-time animated canvas visualizing active audio frequency output.
- **Top Action Switch:** A smooth toggle switch that activates/deactivates the Premium Pass.
- **3-Mode Payment Modal:** Displays three distinct payment gateways upon switch activation:
  1. Credit / Debit Card (Visa, Mastercard, Amex)
  2. Express Wallet (Apple Pay, Google Pay)
  3. Crypto Wallet (USDC, Ethereum, Solana)
- **Interactive Toast Notifications:** Contextual feedback popups for payment selection and track loading.

### ⚡ SaaSify (Landing Page Layout Clone)
- **Responsive Navigation:** Clean navbar with brand identifier and mobile toggle menu.
- **Terminal Component:** Dark mode interactive code box preview for CLI/Deployment tracking.
- **Grid & Flexbox Layouts:** Modern CSS Grid architecture for feature cards and pricing tiers.
